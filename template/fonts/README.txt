Latin Modern fonts used by the elteikthesis Typst port
=======================================================

Unmodified OpenType files of the Latin Modern family (version 2.004),
copyright 2003-2009 B. Jackowski and J. M. Nowacki on behalf of the TeX
users groups, taken from the CTAN package `lm` (fonts/lm, distribution
2.005). Licence: GUST Font License (GUST-FONT-LICENSE.txt), i.e. the LaTeX
Project Public License 1.3c or later. The files are distributed unchanged
and under their original names.

  lmroman12-regular.otf, lmroman12-bold.otf, lmroman12-italic.otf,
  lmromanslant12-regular.otf            body text, headings (cmr12, cmbx12,
                                        cmti12, cmsl12)
  lmroman10-regular.otf, lmroman10-bold.otf, lmroman10-italic.otf,
  lmroman10-bolditalic.otf              \small, \footnotesize, bold italic
  lmroman6-regular.otf                  \tiny (listing line numbers)
  lmromancaps10-regular.otf             title page small capitals (cmcsc10)
  lmmono10-regular.otf, lmmono12-regular.otf
                                        code listings, \texttt, URLs

Typst finds them with `--font-path template/fonts` (see the Makefile).
